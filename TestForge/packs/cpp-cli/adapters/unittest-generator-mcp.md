# UnitTest_Generator_MCP

- Repo: https://github.com/ajithksr/UnitTest_Generator_MCP
- MCP server using libclang AST analysis + LLM host to generate/verify GoogleTest suites.
- Includes boundary/equivalence/MCDC baselines and CMake/LCOV integration.
- Useful when you want an agent-driven C++ unit-test loop inside Claude Code/Cursor.
