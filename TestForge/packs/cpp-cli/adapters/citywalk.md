# CITYWALK / LISA (research)

- CITYWALK: LLM-based C++ unit test generation with project-dependency awareness and language-specific knowledge (ACM 2026).
- LISA: LLM-based invariant testing for C/C++ libraries using Clang AST and API call sequences (arXiv 2607.18711).
- Use them as reference designs for a C++ test-generation prompt/skill; do not assume production readiness.
- C++ LLM generation still struggles with compilation, mocking, and undefined behavior; always compile and run.
