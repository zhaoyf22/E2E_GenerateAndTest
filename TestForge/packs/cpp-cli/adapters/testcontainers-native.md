# testcontainers-native

- Repo: https://github.com/testcontainers/testcontainers-native
- C/C++ binding for Testcontainers, built on the Go implementation as a shared library.
- Requires CMake, Docker, Go 1.19+, and a C/C++ toolchain; CTest integration.
- Demos include GoogleTest and WireMock modules; still early-stage and build-from-source.
- Use for integration tests that need a real PostgreSQL/Redis/HTTP dependency.
