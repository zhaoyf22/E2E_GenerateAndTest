# jqwik

- Property-based testing for JVM; `@Property`, `@ForAll`, `@Provide`.
- Latest 1.10.x. **Note: jqwik 1.10+ ships with an Anti-AI Usage Clause.**
- Confirm the clause with your legal/OSS policy before using it for AI-generated tests.
- Good for invariants, algebraic properties, and stateful/model-based tests.
